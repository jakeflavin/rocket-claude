# Rocket Claude

Rocket Claude is a Claude Code powered replacement for Rocket Money. The app will transform and categorize bank statements into transactions for display in a personal finance dashboard.

## Getting Started

Install dependencies:

```sh
npm install
```

Start the development server:

```sh
npm run dev
```

Create a production build:

```sh
npm run build
```

## Tech Stack

- React
- TypeScript
- Vite
